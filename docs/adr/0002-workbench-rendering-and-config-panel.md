# 工作台在插件自己的面板里自建网格，配置面板是面板内的抽屉

DSH 外壳只提供 keyed 的 `main` 全局面板、侧栏入口和 `shell.overlay`，**没有面板网格/切分**；会话面板 `conversation` 的 `conversation.content` 也不接受独立指定的 Session（需要尚未提供的 Session-provider 能力）。因此工作台的渲染与配置全部由本插件在自己的主面板内实现：

- 主面板（沿用 key `hello-word`）渲染 CSS Grid：`repeat(cols, minmax(0,1fr))` 列 + 等分行，子面板按 `col`/`row`/`w`/`h` 落位，`type → React 渲染器表`，未注册类型显示灰字而不报错。
- 配置面板是**主面板内的右侧抽屉**（宽约 380，网格自动缩窄），编辑即重排、300ms 内自动保存；不采用第二个 `main` 面板（切走就看不到成品）与 `shell.overlay` 浮层（盖住工作台，实时预览要另开）。
- v1 的 `harness` 子面板是**会话门牌**而非内嵌对话：显示绑定的会话标题与运行状态，点击用 `uiWorkspace.openSession` 打开该会话。

**后果**：工作台的"多工作台切换"没有外壳级入口，只能在工作台面板顶部条内做下拉与新建；将来若外壳提供会话嵌入或面板网格能力，这两处是升级点，数据模型不变。
